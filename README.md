# PRN Melaka 2026 — Neutral AI Candidate Introduction Studio

This repository contains fourteen independent candidate introduction projects. Each candidate folder has a dedicated `SKILL.md` and `PROMPT.md`.

- Format: 24 scenes × 2.5 seconds = 60 seconds; six 1×4 storyboards (four 9:16 panels each), and 24 individual video prompts.
- All visuals and narration are synthetic editorial illustrations, **not** authentic footage or a candidate's actual words.
- The factual records are dated 2 November 2026. Reverify claims and election information before publishing.
- Descriptions of public programmes distinguish candidate actions from government/organizational results, planned allocations, and candidate/party claims.
- No candidate endorsements or instructions to vote for a person.

## Layout

```text
candidates/
  01_rauf/
    SKILL.md
    PROMPT.md
  ...
  14_aliza/
    SKILL.md
    PROMPT.md
```
